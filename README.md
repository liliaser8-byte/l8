## ЗАВДАННЯ 1. Проект «Динамічний одновимірних масивів».

**Умова (варіант 13):** Підрахувати кількість додатних елементів у даному одновимірному масиві.

**Реалізація:** Двома окремими програмами — за допомогою вказівника і за допомогою `vector`.

### Програма 1. Вказівник

```cpp
#include <string>
#include <cstdlib>
#include <ctime>
#include <vector>

	private: System::Void button1_Click(System::Object^ sender, System::EventArgs^ e) {
		// створення масиву та заповнення його випадковими числами
		int size = 10;
		int* arr = new int[size];
		int countPositive = 0; // лічильник для додатних елементів

		for (int i = 0; i < size; i++) {
			arr[i] = rand() % 21 - 10; // генерування випадкових чисел від -10 до 10
		}

		// Заповнення DataGridView даними з масиву arr та підрахунок додатних чисел
		for (int i = 0; i < size; i++) {
			// додавання рядка з елементом масиву у DataGridView
			dataGridView1->Rows->Add(arr[i].ToString());

			// перевірка: якщо елемент масиву більший за 0
			if (arr[i] > 0) {
				countPositive++;
			}
		}

		// виведення результату за допомогою MessageBox
		String^ message = String::Format("Кількість додатних елементів: {0}", countPositive);
		MessageBox::Show(message);

		// звільнення пам'яті масиву
		delete[] arr;
	}
private: System::Void MyForm_Load(System::Object^ sender, System::EventArgs^ e) {
	dataGridView1->ColumnCount = 1;
	dataGridView1->Columns[0]->Name = "Value";
}
```

**Як працює програма:**

1. **Ініціалізація та генерація:** При натисканні на кнопку створюється масив із 10 елементів. Перший цикл заповнює його випадковими числами в діапазоні від -10 до 10.
2. **Обробка та виведення:** Другий цикл по черзі бере кожне число з масиву і додає його як новий рядок у візуальну таблицю `DataGridView`. Одночасно програма перевіряє, чи є число додатним (`arr[i] > 0`). Якщо умова виконується, лічильник `countPositive` збільшується на одиницю.
3. **Результат:** Підсумкова кількість знайдених додатних чисел виводиться на екран за допомогою інформаційного вікна `MessageBox`.
4. **Очищення:** Після завершення роботи програма звільняє оперативну пам'ять, яку займав масив.

**Як використано вказівник (`int* arr`):**

* **Виділення динамічної пам'яті:** Рядок `int* arr = new int[size];` створює вказівник `arr`. Оператор `new` виділяє в оперативній пам'яті місце для 10 цілих чисел (`int`), а вказівник `arr` зберігає адресу початку цього блоку пам'яті.
* **Доступ до елементів (адресація):** У циклах вказівник використовується разом з індексатором `arr[i]`. Під капотом це працює як арифметика вказівників: програма відступає від початкової адреси на `i` позицій, щоб записати або зчитати конкретне число.
* **Звільнення пам'яті:** Команда `delete[] arr;` використовує цей вказівник, щоб повідомити системі, який саме блок пам'яті потрібно звільнити. Це обов'язковий крок при роботі з вказівниками для запобігання витокам пам'яті.

## ЗАВДАННЯ 2. Проект «Динамічний двовимірний масив».

**Умова (варіант 13):**  Домножити всі елементи матриці на мінімальний елемент.

**Реалізація:** За допомогою Vector.
### Код

```cpp
#include <string>
#include <cstdlib>
#include <ctime>
#include <vector>

private: System::Void button2_Click(System::Object^ sender, System::EventArgs^ e) {
	// Зчитування кількості рядків та стовпців з текстових полів
	int rows = Convert::ToInt32(textBox1->Text); //
	int cols = Convert::ToInt32(textBox2->Text); //

	// Створення двовимірного динамічного масиву
	std::vector<std::vector<int>> matrix(rows, std::vector<int>(cols)); //
	Random^ rand = gcnew Random(); //

	// Очищення DataGridView перед новим виведенням
	dataGridView2->Rows->Clear(); //[cite: 6]
	dataGridView2->Columns->Clear(); //[cite: 6]

	// Створення колонок для DataGridView
	for (int j = 0; j < cols; j++) {
		dataGridView2->Columns->Add("Column" + j, "Column " + (j + 1)); //[cite: 6]
	}

	// Змінна для зберігання мінімального елемента (початкове значення - максимум з діапазону)
	int minElement = 100;

	// 1. Генерація матриці та пошук мінімального елемента
	for (int i = 0; i < rows; i++)
	{
		std::vector<int> row; // Створення нового рядка[cite: 6]
		for (int j = 0; j < cols; j++)
		{
			int num = rand->Next(1, 100); // генеруємо число від 1 до 99[cite: 6]
			row.push_back(num); // додаємо у рядок[cite: 6]

			// Перевіряємо, чи є поточне число меншим за знайдений раніше мінімум
			if (num < minElement) {
				minElement = num;
			}
		}
		matrix[i] = row; // Записати рядок у матрицю[cite: 6]
	}

	// 2. Домноження елементів на мінімальний та виведення у DataGridView
	for (int i = 0; i < rows; i++)
	{
		// Додавання порожнього рядка до DataGridView розміром cols
		dataGridView2->Rows->Add(gcnew array<Object^>(cols)); //[cite: 6]

		for (int j = 0; j < cols; j++)
		{
			// Домножуємо кожен елемент на знайдений мінімум
			matrix[i][j] = matrix[i][j] * minElement;

			// Записуємо нове значення у комірку таблиці
			dataGridView2->Rows[i]->Cells[j]->Value = matrix[i][j]; //[cite: 6]
		}
	}

	// Виведення повідомлення з інформацією про знайдений мінімальний елемент
	MessageBox::Show("Мінімальний знайдений елемент (до множення): " + minElement.ToString(), "Результат"); //[cite: 6]
}

```

Програма працює у два основні етапи:

1. **Генерація та пошук:** Спочатку вона зчитує розмір матриці, створює її і заповнює випадковими числами від 1 до 99. Одночасно з цим вона перевіряє кожне число і запам'ятовує **найменше** з них.
2. **Обчислення та виведення:** Оскільки найменше число стає відомим лише після повної генерації матриці, програма запускає другий цикл. Вона бере кожен елемент, множить його на знайдений мінімум і відображає цей фінальний результат у таблиці на екрані.

Наприкінці програма показує спливаюче віконце, щоб ви побачили, на яке саме мінімальне число були помножені всі елементи.

У цій програмі `std::vector` використано як сучасну, безпечнішу та зручнішу альтернативу традиційним "сирим" динамічним масивам (тим, що створюються через `new` та `delete`), які були у вашому першому прикладі. Вектори автоматично керують пам'яттю, тому їх не потрібно очищати вручну.

Ось як саме він застосовується:

1. **Створення матриці (вектор векторів):**
Рядок `std::vector<std::vector<int>> matrix(rows, std::vector<int>(cols));` створює основну структуру. Це ніби велика коробка (`matrix`), у якій лежать менші коробки (рядки), а в кожній з них є місце для певної кількості чисел (стовпці). Ми одразу вказуємо, скільки потрібно рядків (`rows`) і стовпців (`cols`), щоб програма виділила необхідну пам'ять.

2. **Заповнення рядка по одному елементу:**
Всередині першого циклу створюється тимчасовий вектор `std::vector<int> row;`. Цей рядок спочатку порожній. Далі програма генерує випадкове число і використовує команду `row.push_back(num);`. Ця команда бере згенероване число і "дописує" його в кінець поточного рядка. Вектор сам розширюється, щоб вмістити нове значення.

3. **Запис готового рядка в матрицю:**
Коли внутрішній цикл завершує роботу (тобто всі числа для одного рядка згенеровані і додані через `push_back`), готовий рядок поміщається у відповідне місце основної матриці: `matrix[i] = row;`.

4. **Зчитування та зміна даних:**
У другому циклі доступ до елементів відбувається так само просто, як і у звичайних масивах — за допомогою квадратних дужок: `matrix[i][j]`. Ми беремо значення з конкретної комірки, множимо його на мінімальний елемент і записуємо результат назад у цю ж комірку вектора.

**Висновок**

Під час виконання лабораторної роботи я успішно закріпила практичні навички роботи з динамічною пам'яттю та програмного використання вказівників при опрацюванні масивів. У ході роботи було реалізовано два підходи до управління даними:

* **Робота з класичними вказівниками:** У першому завданні створено одновимірний динамічний масив за допомогою оператора `new`. Було розроблено алгоритм підрахунку додатних елементів із подальшим відображенням результату, а також успішно застосовано обов'язковий етап ручного звільнення оперативної пам'яті за допомогою `delete[]`, що запобігає її витокам.
* **Використання контейнера `std::vector`:** У другому завданні застосовано сучасну, безпечнішу альтернативу "сирим" масивам для створення двовимірного динамічного масиву. За допомогою вектора було реалізовано алгоритм пошуку мінімального елемента та множення на нього всіх елементів матриці. Вектор дозволив уникнути ручного керування пам'яттю завдяки автоматичному розширенню (`push_back`) та самостійному очищенню.
* **Інтеграція з графічним інтерфейсом:** Для обох завдань налаштовано візуальне відображення згенерованих та оброблених даних у віконному додатку за допомогою компонента `DataGridView`, а виведення підсумкових результатів реалізовано через інформаційні вікна `MessageBox`.

Виконання цих завдань дозволило на практиці дослідити та порівняти низькорівневе управління пам'яттю за допомогою вказівників із сучасним підходом на базі стандартної бібліотеки шаблонів (STL), підтвердивши зручність векторів для опрацювання складних двовимірних структур.
